# dsh-superagent-signal

A Signal Source for [dsh-superagent](https://github.com/lkshrk/dsh-superagent): the owner's messages in one Signal group become Triggers, through the [signal hub](https://github.com/lkshrk/signal-hub).

Requires dsh-superagent `>= 0.3.0`. Documentation follows with the first release.
